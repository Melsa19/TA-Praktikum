Sistem Manajemen Booking Salon – TheGirlsClub

Deskripsi Project

Project ini merupakan mini project mata kuliah Sistem Informasi Berbasis Web. 
Saya membuat sebuah website Sistem Manajemen Booking Salon dengan konsep sederhana yang berfungsi untuk mengelola data booking pelanggan.

Website ini dibuat menggunakan HTML5, CSS eksternal, dan Bootstrap 5 (CDN). 
Tampilan dibuat responsif sehingga dapat menyesuaikan ukuran layar desktop maupun mobile.
